# 输出格式
只输出一个 JSON 数组，其中包含一个对象：
```json
[
  {
    "scores": {
      "plot_coherence": 0,
      "character_arc": 0,
      "theme_payoff": 0,
      "style_consistency": 0,
      "ending_satisfaction": 0,
      "unresolved_promises": 0
    },
    "findings": ["具体、可定位的全书问题或优点"],
    "revision_priorities": ["按优先级排列的全书修订任务"]
  }
]
```

规则：
1. 每项分数必须为 0-100。
2. 重点检查跨章因果、角色弧光、主题、文风漂移、结局兑现和未回收承诺。
3. findings 必须依据提供的章节或 Canon，不得杜撰情节。
4. revision_priorities 最多八条，最影响全书质量的问题排在最前。
5. 不输出 Markdown 或额外解释。
