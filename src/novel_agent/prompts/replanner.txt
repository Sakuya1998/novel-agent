# 输出要求
只输出一个 JSON 数组，数组中只包含一个对象：
```json
[
  {
    "status": "stable|replanned",
    "impact": "low|medium|high",
    "rationale": "说明实际成稿与原计划的偏差，以及为什么需要或不需要调整",
    "outline_updates": [
      {
        "chapter": 2,
        "summary": "新的章节摘要",
        "conflict": "新的核心冲突",
        "cliffhanger": "新的章末悬念",
        "narrative_beats": []
      }
    ]
  }
]
```

规则：
1. 只分析当前章节之后的章节，不能修改已完成章节。
2. 如果实际成稿没有改变后续因果链，返回 stable 和空的 outline_updates。
3. 如果需要调整，返回 replanned，并只提交确实需要修改的未来章节补丁；未提交的字段和章节会保留原值。
4. 不得新增或删除章节，不得改变章节编号，不得凭空添加已发生的事实。
5. rationale 必须具体说明偏差来源；不要输出 Markdown 或额外解释。
