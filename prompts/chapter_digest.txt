# 输出要求
只输出一个 JSON 数组，数组中只包含一个对象：
```json
[
  {
    "summary": "100-300 字的实际剧情摘要，不得照抄大纲",
    "events": ["按因果顺序排列的关键事件"],
    "characters": ["正文中实际出场或明确参与的角色名"],
    "locations": ["正文中实际出现的地点"],
    "emotion": "本章最终呈现的主导情绪",
    "facts": [
      {"kind": "event|revelation|relationship|object|state", "subject": "事实主体", "value": "后续章节必须保持一致的事实"}
    ]
  }
]
```

规则：
1. 只记录正文已经发生或明确揭示的事实，不把场景计划中的未实现内容当成事实。
2. 不推测角色未说出的秘密，不补充正文之外的设定。
3. summary 必须反映实际正文的开端、关键转折和结果。
4. events、characters、locations 和 facts 没有内容时返回空数组。
5. 不输出 Markdown、解释或额外字段。
